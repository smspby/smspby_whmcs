# SMSp.by для WHMCS

Модуль отправляет SMS из WHMCS и подтверждает номера телефонов с помощью OTP.

## Совместимость

Один пакет рассчитан на несколько версий PHP. Веб-сервер и cron должны использовать версии PHP, совместимые с вашей установленной версией WHMCS. Для отправки SMS требуется расширение cURL.

| PHP | Целевые версии WHMCS | Статус PHP |
| --- | --- | --- |
| 7.4, 8.1 | 8.13 | Совместимость для существующих установок. Поддержка со стороны проекта PHP завершена |
| 8.2 | 8.13, 9.0, 9.1 | Исправления безопасности до 31 декабря 2026 года |
| 8.3 | 8.13, 9.0, 9.1 | Исправления безопасности до 31 декабря 2027 года |
| 8.4 | 9.1 | Исправления безопасности до 31 декабря 2028 года |

Автоматические проверки с заглушками WHMCS охватывают синтаксис PHP, загрузку модуля, хуки и рендеринг шаблона. PHP 8.5 входит в эти проверки модуля. Версии PHP для установки выбирайте по таблице и требованиям вашей версии WHMCS.

[Требования WHMCS 8.13](https://docs.whmcs.com/8-13/installation-guide/system-requirements/) · [Требования WHMCS 9.0](https://docs.whmcs.com/9-0/installation-guide/system-requirements/) · [Требования WHMCS 9.1](https://docs.whmcs.com/9-1/installation-guide/system-requirements/) · [Сроки поддержки PHP](https://www.php.net/supported-versions.php)

## Установка и обновление

1. Распакуйте ZIP в каталог `modules/addons/smspby_whmcs/` вашей установки WHMCS. Файл `smspby_whmcs.php` должен лежать непосредственно в этом каталоге.
2. При первой установке активируйте SMSp.by в списке модулей и задайте права доступа администраторам. Откройте настройки модуля и укажите учётные данные API.
3. При обновлении сделайте резервную копию каталога модуля и базы данных, затем замените файлы. Деактивация удаляет таблицы модуля.
4. Проверьте открытие настроек, отправку тестового уведомления и подтверждение номера тестового аккаунта, если используется OTP.

## Сборка и проверка

`./zip.sh` создаёт `smspby_whmcs.zip` в корне репозитория. Команда `php tests/smoke.php` запускает проверку без установки WHMCS и без отправки SMS.
